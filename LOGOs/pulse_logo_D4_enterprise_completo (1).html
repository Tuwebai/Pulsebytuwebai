8 tests de validación — enterprise
✓
Test de silueta
El pico + valle de la onda dentro del círculo es reconocible como silueta pura. Sin color ni texto, la forma comunica actividad y monitoreo.
✓
Test de escala
A 14px: el pico de la onda domina, el punto activo es el único color. A 400px: el grosor ultra fino del círculo crea tensión con el trazo más grueso de la señal.
✓
Test de tiempo
El círculo y la onda sinusoidal son geometrías universales sin fecha. No hay referencia a ninguna tendencia de UI ni año específico.
✓
Test de unicidad
El contraste de opacidad entre círculo fantasma (15–18%) y onda sólida es inusual. Los competidores usan círculos rellenos o sin contraste de peso.
✓
Test de separación
El símbolo funciona solo como app icon. "PULSE by TuWebAI" funciona solo en texto plano, footer de emails, documentos PDF.
✓
Test B&W
En negro puro sobre blanco la forma funciona perfectamente. El azul del punto activo es contextual, nunca estructural.
✓
Test de inversión
La versión nocturna es la versión principal del producto — el dashboard vive en dark navy. Diseñada primero para ese contexto.
✓
Test de explicación
"Un círculo que contiene la señal de tu negocio. El punto azul es el dato llegando ahora mismo." — menos de 10 segundos.
